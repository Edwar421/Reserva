# Frontend

Aplicación frontend del sistema de reservas, construida con Vite, React y TypeScript/JavaScript.

## Requisitos

- Node.js instalado
- El backend ejecutándose en `http://localhost:3000` o disponible en la URL que use el frontend

## Instalación

```bash
npm install
```

## Ejecución

```bash
npm run dev
```

## Pruebas

```bash
npm run test
```

## Notas para repositorios separados

Este directorio está preparado para vivir como repositorio independiente. Si el backend se publica en otra URL, conviene centralizar esa dirección en una variable de entorno antes de desplegar.
